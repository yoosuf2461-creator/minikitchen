## 📌 Project Overview

**MiniKitchen** is an artisanal seasonal dining web application and management platform built with Next.js 16 (App Router), Google Gemini API, Supabase Cloud PostgreSQL, and Tailwind CSS v4.

### Key Features:
- **Artisanal Dining Website**: Bespoke typography (`Italiana` & `Outfit`), custom dark luxury aesthetic, and smooth scrolling.
- **AI Concierge ("Remy")**: Powered by Google Gemini 2.5 Flash for inquiries and conversational table bookings with strict pending status disclaimers.
- **Operational Admin Portal**: Table reservation approvals, 1-click notification dispatch (WhatsApp, SMS, Gmail, Outlook, Mail app), and real-time menu availability toggling (`Available` $\leftrightarrow$ `Sold Out`).
- **Cloud Persistence**: Supabase PostgreSQL database for real-time multi-device synchronization with a local atomic JSON backup fallback.
